agentmail setup

First-time initialization. Set the admin password and mail domain to create the system.

This creates the admin account (admin@<domain>) with the password you choose. After setup, the panel asks for these credentials to log in. You can register more accounts from the panel.

agentmail login

Sign in with your mail account. Admins see the full panel; regular accounts see a personal view.

Register a new account

agentmail register

Pick a name for your account; a password will be generated.
